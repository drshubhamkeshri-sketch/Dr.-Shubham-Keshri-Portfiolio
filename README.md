# Dr. Shubham Keshri — Executive Portfolio Architecture

Separated micro-architecture for **Dr. Shubham Keshri Portfolio**:
- **`backend/`**: Express REST API server with MongoDB Atlas & Cloudinary CDN (deployed on [Render](https://dashboard.render.com)).
- **`frontend/`**: Executive Web Application with Three.js 3D Engine (deployed on [Vercel](https://drshubhamkeshri.vercel.app)).

Each directory is 100% self-contained with its own `node_modules`, `package.json`, and `.env` configuration.
